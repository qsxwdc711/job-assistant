# S5 长亭官方来源接入计划

> 按既有已确认来源设计继续本批扩展，在本会话逐项执行。采用独立 worktree，不增加自动投递、真实发送或账号权限。

**Goal:** 恢复今日已有来源更新，并接入长亭官网直接授权的当前公开招聘站，分别保留校招、实习和明确低经验岗位。

**Architecture:** `www.chaitin.cn → join.chaitin.cn/plugins/career_site/sites/default`。沿用公开匿名读取、完整分页、同 ID 详情核对、适用条件保留、原子发布和失败保留规则。来源只配置固定公开域名与站点 default；网页中本地调试地址不访问、不执行。申请入口是官方岗位页的邮件投递说明，既不替用户登录邮箱也不发送邮件。

**Tech Stack:** Go 1.26.8、已有 x/net/html、PostgreSQL、现有 worker/CLI/Vue 与独立 Edge 验收。

## 3. 条件与类型

- [x] 依据官方岗位类别与实际职责判断技术范围；排除销售、产品、售前、职能、项目经理等。安全/HIDS/Security 为 security；AI 模型/算法为 algorithm_ai；技术支持只有明确 Linux 运维/部署/故障处理职责才归 operations_sre，不称为后端研发。
- [x] `work_type=internship` 单独归实习，不因站点标签 social 变成正式社招；明确实习标题与 full_time 冲突时保留待核验。`campus+full_time` 归校招，social 全职仅在有明确接受应届或最低经验不超过一年依据且无更高硬门槛时发布。
- [x] 年限按条件子句核对，优先/加分与硬性门槛分开；同时包含硬要求和优先项时不能整段忽略。完整职责/要求原文保存，不生成个人可投承诺。
- [x] 在校、每周出勤和最短实习月数仅从明确硬条件提取。真实样本“每周至少到岗4天，实习期不少于6个月”必须得到 4/6，不能沿用旧来源不匹配的正则后默默当作不限。
- [x] 笔试、毕业日期窗口及截止未披露时保持 unknown；标题 2027届保留为原文，不凭届数编造境内/海外日期。地点复用 Locations，新疆/山西不能补造地级市。
- [x] 投递链接始终是官方岗位详情 HTTPS URL；邮件地址、主题模板和追踪码放在批次依据，说明需要本人按官方说明发邮件，LoginRequired=false，不创建 mailto 自动发送动作。
- [x] 使用现有 matching.Evaluate 实际验证本科明确门槛、在校/出勤/时长不足及未知条件；推荐权限逻辑保持既有行为。
