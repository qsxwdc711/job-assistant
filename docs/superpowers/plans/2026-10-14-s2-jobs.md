# S2 官方岗位与个人投递 Implementation Plan

> For agentic workers: 在当前 `codex/s2-jobs` 分支串行执行，不自动启用代理。延续已批准的 V1 设计与阶段计划；修改 Go 功能后执行 go-feature-change-review 和 go-code-review。

**Goal:** 将腾讯、华为、招商银行的实时官方岗位接入可登录的电脑/手机看板，完成组合筛选、官方溯源、收藏和个人投递闭环。

**Architecture:** Go 的 catalog、ingest、application 模块共用 PostgreSQL；公开内容按来源与批次保留版本和方向，个人记录按当前会话归属。来源采集由独立 CLI 串行运行，管理员维护来源、公司标签和岗位发布状态。Vue 网页通过同源代理调用已有身份 API；每日可靠调度与飞书仍按 S4 实现。

**Tech Stack:** Go 1.26.8 / pgx、PostgreSQL 18.6、Vue 3 / TypeScript / Vue Router / Pinia / Vite、Playwright、Docker Compose。

## 1. 数据与授权基础

Files: `backend/migrations/0002_catalog.sql`、`0003_applications.sql`、`backend/internal/catalog/model.go`、`filter.go`、`store.go`、`maintenance.go`、`backend/internal/identity/access.go`。

- [x] 先写真实数据库行为测试：外部大整数 ID 原样保存、来源/批次唯一、重复读取不增加内容版本、截止变更增加版本、方向与城市同时筛选不跨方向拼接。
- [x] 实现 companies、sources、campaigns、jobs、job_versions、job_variants、job_locations、job_tags、dictionary_entries、ingest_runs。岗位保存官方链接、链接级别、登录要求、三态笔试、未知条件、原始文本依据及核验时间。
- [x] 将当前操作者复核封装为身份事务函数；公共查询须登录，个人及管理操作在事务内复核当前权限，不能重用过期角色对象。
- [x] 行业/性质/规模标签作为可扩展字典。初始未核实企业性质或规模为 unknown，管理员修改需提供依据并原子记录审计。

API contract: `GET /api/v1/jobs?q=&company=&direction=&major=&city=&industry=&nature=&tier=&graduation_year=&recruitment_type=&written_test=&deadline_before=&status=&include_unknown=true&sort=updated&limit=20&offset=0` returns `{items,total,limit,offset}`；`GET /jobs/{id}` returns `{job}`；字典由 `GET /jobs/filters` 提供。地点与方向等组合条件在同一岗位方向内匹配。毕业条件保存国内/海外、学历、真实日期范围及优先条件；过滤不冒充个人资格结论。

## 2. 三个官方来源

Files: `backend/internal/ingest/client.go`、`normalize.go`、`tencent.go`、`huawei.go`、`cmb.go`、`run.go`、`backend/cmd/collector/main.go`、`backend/internal/ingest/testdata/`。

- [x] 从 S0 原始公开样本提取真实接口测试数据。先测试成功空结果、业务错误、分页不完整、华为无计数 null、腾讯字符串大 ID、HTML 纯文本与未知笔试。
- [x] 只请求 S0 已证明的公开招聘页面和查询接口。设置请求/整体时间、响应大小和分页上限，串行请求，检查 HTTP、业务码、结构、记录数及身份唯一性。受限页面立即失败并记录，不绕过登录/验证码。
- [x] 腾讯从当前项目子批次取毕业依据，不继承过时父菜单。华为保留广告/意向/部门城市组，不以广告占位 JD 代替方向条件。招商将实习“2027 届优先”保存为偏好；公告与岗位分开。
- [x] 每来源完整成功后原子发布其岗位和版本；失败不变更旧岗位状态，成功空列表也不关闭旧岗位。原文中未披露的截止、笔试、专业和学历保持 unknown。
- [x] `collector all` 逐来源隔离失败；`collector tencent-campus` 等可单来源运行，返回来源结果和真实数量，不输出配置/凭据。完成两次实采并对比身份与版本。

## 3. 收藏与投递

Files: `backend/internal/application/model.go`、`store.go`、`backend/internal/httpapi/recruitment.go`、`applications.go`、`catalog_admin.go`；修改 `handler.go` 和 `cmd/api/main.go`。

- [x] 先测试两用户收藏和投递读写隔离、管理员访问、重复创建、并发 version 冲突、岗位关闭后个人记录保留、账号停用/管理员降级后的旧对象拒绝。
- [x] 实现本人收藏列表、添加/移除，以及投递创建、列表、详情、修改、删除；状态支持 draft/submitted/written_test/interview/offer/rejected/withdrawn，允许人工修正。
- [x] 投递记录具有 owner/job 唯一约束、version、备注、下一步事项、事项日期和事件历史。每次修改条件包含预期 version，冲突返回 409，事务回滚不产生孤立历史。
- [x] 管理员接口维护公司标签、来源启停和岗位发布状态，并可按 owner 查阅/维护个人业务记录，所有管理修改记录审计。

API contract: `/me/favorites`、`/me/favorites/{jobID}`；`/me/applications`、`/me/applications/{id}`、`/me/applications/{id}/events`；对应 `/admin/applications`；`/admin/companies`、`/admin/sources`、`/admin/jobs/{id}`。私有越权为 404、无能力为 403、version 冲突为 409。CSRF 延用 S1。
