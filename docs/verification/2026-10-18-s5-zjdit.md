# S5 中久官方来源验收

日期：2026-10-18，Asia/Shanghai。范围为一个新增官方技术来源、表单/HTML 读取能力及可选本机公共采集进程。飞书继续按用户选择为模拟模式；本批不宣告整个 S5 完成。

## 验证范围与当前结果

改动前 ingest、matching、catalog、task 包基线通过。新增单测先因 Reader.ZJDIT/详情校验未实现而编译失败，完成实现后通过；其后 ingest/matching 全包回归和原生 go vet 通过。

单测使用七条脱敏公开列表记录及三个真实详情主面板，验证列表表单参数、匿名会话生命周期、完整分页、有效空结果、跨页重复、总数变化、缺页、错误类别、业务失败、HTTP 403 不重试和晚到坏详情不返回部分文档。详情核对限定主面板，侧栏、通用登录页及重复主面板不能替代事实。

资格验证实际调用现有 matching.Evaluate：零工作经验的硕士不会因社招专属三年条件被拒绝；本科会被明确硕士学历要求排除；未限定社招的三年要求不因校招标签被忽略。模型语义不得覆盖资格结果。

三次 Windows 原生独立匿名完整读取的候选文档一致：26 条列表，12 个候选，每次 18 个请求，归一化哈希为 `268a0d90eac243eca3886f63f0112d42e5bf4f1cdfd87bd56b8ae98df3e61106`。真实空查询 count=0/data=[] 已验证；不存在详情返回 HTTP 500，不据此判为关闭。

- 第一轮 `job-assistant-s5-zjdit-verify-030f451e` 的镜像、真实 PostgreSQL、全量 Linux race、五个电脑/手机浏览器流程和正常关闭通过。
- 审查补充反例发现“校招和社招需三年”不能按社招独有限定删除。新增反例先失败，收紧子句边界后通过；同时验证详情页自身 ID 标记，不能只凭侧栏相似信息接受错误 ID。
- 第二轮 `job-assistant-s5-zjdit-verify-ea107235` 失败：既有 `TestMokaSourcesShareDomainAndGlobalReadLimits` 在数据库连接握手阶段超时（120.37 秒），不计通过。没有放宽读取上限或跳过该测试。
- 最终轮 `job-assistant-s5-zjdit-verify-49025660` 构建镜像、`go vet ./...`、真实 PostgreSQL 下 `go test -race -count=1 -v ./...` 通过，集成包 42.367 秒，强制核对关键测试执行且没有 SKIP。包含新来源完整/重复/晚到失败/空结果、原来源隔离，以及本机/容器领取范围、配置拷贝、中断重试；原 Moka 全局三个读取上限和同域互斥测试通过。

最终轮之后只修改 PowerShell 本机手动采集路由、启动就绪等待及文档，完成 PowerShell 语法检查；它们的正式本机操作仍须在下节补验。

## 来源网络差异与运行方式

Windows curl/Go 匿名 HTTPS 均可读取。Docker 中相同域名 Go/curl 经现有代理、直连及另一公开 A 记录均发生 TLS EOF；关闭混合密钥交换没有改善。未关闭证书校验，未处理登录或 WAF 挑战。临时网络转发诊断启动被自动审批以 `blocked by policy` 拒绝，服务未启动，也未通过别的方式重试。

采用可选本机公共采集进程作为应用运行时：只领取 `COLLECTOR_HOST_SOURCES` 指定来源，容器排除这些来源；每日计划和摘要仍由原 worker 负责，实际读取继续共享数据库全局/同域锁、租约、暂停与重试。本机进程无监听端口，不加载私有任务、模型和飞书逻辑，凭据不写入命令行或日志。未配置该项时保持原容器行为。生产环境仍需验证新来源自动领取和重复采集，不把原生读取成功等同于容器网络恢复。
