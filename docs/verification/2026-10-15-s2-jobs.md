# S2 官方岗位与个人投递验收

日期：2026-10-15，Asia/Shanghai。分支：`codex/s2-jobs`。S2 完成，S3–S5 保持后续阶段。

## 可使用的结果

本机 Docker 应用入口为 http://127.0.0.1:8080，网页与 API 同源。管理员凭据来自本机忽略的 `.env`，没有写入代码、截图或本文。项目数据库使用独立持久卷；临时浏览器账号和状态只进入专用 `_test` 数据库。

- 电脑列表/表格与手机浏览器布局；组合筛选、分页、排序、URL 保留条件。
- 岗位专业、方向、地点、行业、企业性质、规模、毕业年份、招聘类型、三态笔试、截止日期与公司/关键词筛选。未核实公司性质或规模不猜测填充。
- 官方溯源与投递直达链接；华为意向、部门城市和职责要求分别成组。官方申请仍需要用户自己登录对应平台。
- 本人收藏、投递状态、个人备注、下一步事项、事项时间和版本历史；管理员维护账号、标签、来源与公共岗位。管理员跨账号投递维护由受权 API 提供，网页投递页当前显示本人记录。

“记录投递”只建立管理记录，不向公司提交申请。截止时区未知时只展示官方日期；腾讯当前详情没有明确开放状态，保留为状态待确认。毕业年份筛选是范围查找，个人境内外、学历及优先条件仍需看详情；尚未提供个人简历资格结论。

两轮均完整成功，最终公开 **58 个岗位广告**。全库 71 个已存身份对比：UUID、外部身份、内容哈希、版本和发布状态均无差异；第二轮三个来源 `changed_count` 均为 0。请求尝试数可能含暂时 EOF/超时重试，成功响应证据数量分别为 22、66、45。

分类核对发现，宽泛的职责关键词曾误收宏观经济、供应链及部分材料/硬件岗位；13 条历史候选已隐藏待复核，保留版本，不标为关闭。另一处过窄规则漏掉明确的 AI 全栈、云开发、AI 应用与数据科学岗位；修正后核对五条官方职责，并通过管理员 API 恢复发布，保留审计。

采集范围：腾讯常规校招中国地点，华为应届研发计算机方向，招商校招与实习。并未覆盖这些公司的全部招聘类别。已实现三个公司采集器，目标公司进度为 3/20；两轮实采不能代表每日调度或七天稳定运行。

此前 Windows 原生读取有 EOF/TLS 超时，华为 Linux 首次读取也有短暂 EOF。增加有限的传输错误重试，正式验证使用 Linux 生产采集程序；401/403/429、业务错误和结构变化立即停止该来源，不尝试绕过限制。失败记录保留旧岗位，成功空结果和单次缺失均不关闭旧岗位。招商旧公告关闭码只用于 S0 证据，当前适配器不会推广为所有岗位的通用关闭码。

## Go 功能与风格复核

应用 `go-feature-change-review` 和 `go-code-review`。检查入口、SQL 授权/归属、源响应解码、原子发布、版本与事务、静态文件边界、设备冲突和部署配置；没有待修复的阻塞项。

Must Fix：无未解决项。Should Fix：下述两项已修复并验证。Nits：无待处理项。机械检查采用 gofmt 和 go vet；未运行 golangci-lint。

已修复的两项可复现问题：

1. **warning / correctness**：组合状态字符串曾通过子串校验，写入 SQL 后返回 500。输入 → 枚举校验 → 应用创建 → 数据库约束 → HTTP 500；新增测试先失败，改为完整枚举匹配后返回 400。复核路径：catalog/filter、catalog/publish、application/store、recruitment_http_test。
2. **warning / data**：管理员代管收藏曾缺少审计。管理接口 → 当前权限与 owner → 收藏写入 → 无审计提交；新增真实数据库测试先失败，补充同事务审计后通过，并用审计触发器失败验证收藏回滚。复核路径：application/favorites、httpapi/applications、application_test。

另外修正了网页登录失败文案、短暂网络失败时的会话缓存处理，以及编辑 VIP 到期时间时的本地时区转换。公开接口和私有写入继续在事务中复核当前权限，前端隐藏按钮不承担安全判断。
