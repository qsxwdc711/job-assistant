# 中小企业线索补验与中久来源接入

日期：2026-10-18，Asia/Shanghai。本批沿用企业官网授权链、公开完整快照及条件适用范围规则。重点推进原先来自高校/公共就业平台的较小技术企业线索；企业规模标签与岗位接入分别验证，不以“已接入”等同于完成法定中小企业认定。

## 官方链与规模证据

[中久数创官网](https://www.zjdit.com/)直接链接[当前招聘站](https://zp.zjdit.com/)，招聘站也提供返回官网链接。主体均为四川中久数创科技有限公司，官网自述从事 CAE 工业软件。当前官网/招聘站均介绍拥有两百余人的 CAE 人才队伍；这与此前高校资料的 50–150 人及旧站百余人资料不同。团队人数不等于全公司员工总数，也不能直接推断企业法律划型；本批继续保留规模和性质标签为未核实。

[汉森官网](https://www.hosonsoft.com/)及[校园招聘页](https://www.hosonsoft.com/about/school/)本次已恢复匿名 HTTPS 读取，之前的 TLS 失败是历史观察。本次页面没有呈现校园岗位；按页面脚本当前栏目 catid=26 查询公开 `/api/docpagejob` 得到 item=[]、totalNum=0、pageSize=12。未找到官网链接到高校简章里的 Moka hosonsoft/96288；不把公司名称相同当作已核实授权链，本批仍不接入该 Moka 租户。此结论不表示公司完全停止招聘，社会招聘页面另有岗位。

## 中久列表与详情

公开[技术岗位页](https://zp.zjdit.com/position/index.html?class_id=1)调用表单编码 POST `/Position/loading_list_data.html`。class_id=1 为技术岗位，page 从 1 开始；本批每页 15，两个分页共 **26 个唯一广告 ID**。与 Moka 的记录偏移分页不同，此处不沿用 offset。

列表提供标题、地点、学历、校招/社招标签、职责与任职要求。逐个技术候选读取 `Position/details.html?id=...`，用 HTML5 DOM 限定唯一主岗位面板核对同一标题、地点、学历、标签、职责、条件及“登录投递”入口。侧栏“最新职位”可能列出不在当前技术列表的历史实习等条目，不作为当前开放列表或本条岗位条件。

code=200、count=0、data=[] 的无匹配查询已实际验证；data=null、缺页、重复 ID、总数变化和业务失败都不当作成功空结果。不存在 ID 的详情实际返回 HTTP 500 与业务错误，不据此推断岗位关闭。

三次 Windows 原生完整匿名采集的 26 个列表 ID 与 12 个入选文档一致，归一化文档 SHA-256 均为 `268a0d90eac243eca3886f63f0112d42e5bf4f1cdfd87bd56b8ae98df3e61106`。每次共 18 次请求：入口、两页列表和 15 个技术候选详情。另有 11 条职责方向未确认属于本版范围、3 条存在未限定范围的超过一年硬性经验要求，排除待人工核验。

## 招聘范围与条件

这 12 条均明确要求硕士及以上，含 C++ 开发、测试开发、并行计算和 CAE 软件研发等；部分岗位要求力学、计算数学、核技术等专业及领域经验，不能直接当作所有计算机专业求职者均可投。专业和学历原文保留，匹配按个人资料逐条判断。

- [C++ 开发（56）](https://zp.zjdit.com/Position/details.html?id=56)同时有校招和社招标签，三年 C/C++ 经验明确仅适用于社招。本版校园文档不继承该年限，完整原文放入批次依据，供用户核对。
- [测试开发（78）](https://zp.zjdit.com/Position/details.html?id=78)要求硕士及以上及相关技术专业；项目或实习经历为优先条件，不生成硬性工作年限。
- [前处理引擎（20）](https://zp.zjdit.com/Position/details.html?id=20)虽然有校招标签，正文却要求三年以上研发经验且未限定社招。条件存在冲突，本批不自行删除年限或推荐给无经验应届生。

本批只去掉明确限定“社招需/社招要求”等的子句。经验适用范围不清楚时保持人工核验，不能因标签包含校招就忽略硬要求。仅社招岗位若缺少接受应届或零至一年经验依据也不直接发布。

毕业日期、截止和本岗位笔试未充分披露，保持 unknown。通用 FAQ 的提前批和机考说明未证明适用于具体广告，不复制到所有岗位。投递链接保留官方岗位详情页，并标明需要登录；没有代替用户注册、投递或发送邮件。
