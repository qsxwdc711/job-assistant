# S3 简历与岗位匹配运行说明

## 本机使用

从项目根目录执行 `./scripts/start-local.ps1`。它先构建网页与镜像、应用迁移，再启动 API 和独立 worker；已有数据库与账号继续使用。网页入口为 `http://127.0.0.1:8080`，侧栏增加“简历资料”和“岗位匹配”。普通账号可以查看自己的文件信息、删除过往简历；正文、下载、资料版本和推荐需要当前有效 VIP 或管理员权限。

1. 上传文字版 PDF 或 DOCX，最多 10 MiB。填写要隐去的姓名或别名。原文件保存在 Docker 的 `private_files` 私有卷中，API 与 worker 共用；不在网页目录下，也不通过静态路径下载。
2. 等待本地提取，核对脱敏预览。常见联系方式、姓名、证件和详细地址会被替换；学校、公司、项目经历仍可能识别个人身份。可以修改预览并保存，保存后需要重新授权。系统不保证完全匿名。
3. 未配置模型时可直接填写资料。配置模型后，只有显式勾选外部处理授权并点击生成草稿，才会将脱敏内容发送给 DeepSeek。模型草稿附原文引用，仍须本人核对。
4. 保存资料会创建不可变版本，并设为当前版本。允许保存多个版本；列表优先显示当前版本，再显示较新的版本。更换当前版本后，旧推荐失效。
5. 在“岗位匹配”搜索并选择岗位，一次最多 20 个。资格检查与语义比较分别展示；广告下的方向与地点分别保留。未公布或无法确定的条件会显示待确认，不自动当作不限条件。

“满足已知条件”不代表企业一定接受，也不代表有某个录用概率。简历没有记录某项技能，只能说明缺少资料证据。明确不满足硬性条件的方向不调用模型。

## 可选 DeepSeek 配置

密钥只填写在本机被 Git 忽略的 `.env`，不要发送到聊天、写入源码或验收报告。

```dotenv
MODEL_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-flash
MODEL_API_KEY=
```

填写有效密钥后执行 `./scripts/start-local.ps1 -SkipBuild`，API 与 worker 会重新读取配置。默认模型采用 [DeepSeek JSON Output 官方示例](https://api-docs.deepseek.com/guides/json_mode/)；实际可用模型、账号权限、费用及中文简历输出质量需在接入真实账号后验收。当前交付只完成隔离模拟验收。

没有密钥时，网页明确显示未配置；解析接口返回 `503 model_not_configured`，不会伪造成功。上传、本地提取、预览编辑、手动确认、版本管理和资格规则仍可使用。语义结果保留为 `not_configured`；配置密钥后再次评估即可排队。HTTP 模型地址仅在显式 development 配置下允许，用于本地适配和隔离测试；默认部署使用 HTTPS。

原生 Go 启动还需安装 Poppler，使 `pdfinfo`、`pdftotext` 位于 PATH，并设置绝对的 `PRIVATE_STORAGE_DIR`。容器已包含 Poppler。Windows 示例：

```powershell
$env:PRIVATE_STORAGE_DIR = [IO.Path]::GetFullPath('.cache/private')
go -C backend run ./cmd/api
# 另一终端使用相同数据库、私有目录和模型配置运行：
go -C backend run ./cmd/worker
```

## 任务、缓存与删除

- HTTP 只提交本地任务，模型处理在独立 worker 中完成。队列只保存账号、资源 ID、版本及处理状态，不保存简历正文或凭据。
- 每次领取有 120 秒租约；一次处理上下文最长 90 秒，模型 HTTP 最长 45 秒；临时网络故障、限流和服务错误最多三次外部尝试，退避后重试。无效 JSON、截断响应和虚构引用不作为成功结果。
- worker 在处理前、回写前重新检查发起人和数据所有者的当前账号状态、权限版本、VIP 有效期、资源版本和租约。撤权、停用、删除、切换资料或岗位变化会阻断过期结果。已成功写入、但尚未完成队列状态的任务恢复时不重复调用模型。
- 缓存包含所有者、确认资料版本、岗位版本、方向键及内容哈希、规则和模型配置版本。岗位到期同样停止语义处理，读取时不返回旧语义结论。
- 删除会清空正文、草稿、敏感姓名，删除资料版本和推荐，取消待处理任务。物理文件使用删除发件箱重试；即使文件暂时无法删除，接口也已不可读取。
- 个人投递关联创建时的资料版本，更换当前资料不改写既有投递。删除简历保留投递及其历史，资料关联置空。
- 管理员通过页面的“资料所属账号”查看或管理其他账号的数据；敏感读取及修改均记录审计，审计不保存正文、原文件名、联系方式或模型输出。

## 接口与隔离验收

本人路由位于 `/api/v1/me`，管理员路由位于 `/api/v1/admin`，后者可使用已校验的 `owner_user_id` 指定账号。

| 接口 | 作用 |
|---|---|
| GET/POST /resumes | 文件信息列表 / 上传并本地提取 |
| GET/DELETE /resumes/{id} | 脱敏详情 / 删除简历与衍生资料 |
| GET /resumes/{id}/download | 经授权下载原文件 |
| PATCH /resumes/{id}/preview | 按 revision 修改脱敏预览 |
| POST /resumes/{id}/parse | 按 revision 与显式 consent 提交解析，返回真实任务信息 |
| POST /resumes/{id}/confirm | 按 revision 确认候选资料，创建并选用新版本 |
| POST /resumes/{id}/versions/{versionID}/activate | 选用已有资料版本 |
| GET /profiles | 当前版本优先的资料列表，最多 100 条 |
| GET /tasks/{id} | 安全的任务进度，不含文档与租约凭据 |
| GET/POST /recommendations | 推荐记录 / 对选择的岗位提交评估 |
| GET /recommendations/{id} | 单条已授权结果 |

执行 `./scripts/verify-s3.ps1` 可复现隔离验收，支持与本机启动相同的 Node/pnpm、GoProxy 和系统代理参数。脚本创建随机 Compose 项目、tmpfs 测试数据库、私有测试卷和独立浏览器账号；模拟提供方只存在于测试镜像，不进入生产镜像，也不调用 DeepSeek。所有文档均为合成测试资料。完成后清理本次容器、网络及私有测试卷；本机数据库和私有文件卷不受影响。

日志与浏览器截图保存在忽略的 `.cache/verification`。浏览器 trace 可能包含临时会话凭据，只供本机排错，不应提交或公开。
