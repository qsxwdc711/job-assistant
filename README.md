# 求职助手 · 计算机方向

面向各行业计算机相关岗位，提供官方岗位看板、条件筛选、投递管理，以及 VIP 简历推荐和飞书群通知。

## 当前进度

2026-10-16：S0–S3 已完成开发与对应本地验收。可登录的电脑/手机网页支持列表与表格、组合筛选、官方溯源、收藏、投递状态、备注、事项和历史。管理员可维护账号、公司标签、来源开关与岗位发布。不同账号数据隔离，多设备同时编辑通过版本冲突提示保护草稿。

三家企业已接入五个独立采集来源，新增腾讯普通／日常实习和华为实习。本机本轮新增 **64 个实习岗位广告**，当前公开共 **122 个计算机方向岗位广告，其中实习 66 个**（2026-10-16 快照，非个人可投数）。S3 已实现私有简历、本地提取与脱敏、资料确认版本及逐方向岗位匹配，并完成模拟模型验收。真实 DeepSeek 账号验收等待本机配置密钥；每日可靠调度和飞书在 S4，20 家扩源、云部署和 7 天观察在 S5。

## 打开与更新

本机入口：**http://127.0.0.1:8080**。当前仅绑定本机；手机布局已用独立浏览器上下文验收，真实手机远程访问在部署后提供。登录账号和密码保存在 Git 忽略的 `.env`，分别为 `ADMIN_USERNAME`、`ADMIN_PASSWORD`。

在 PowerShell 7、Node 22.18+（22 系列）、pnpm 11.25.0 和 Docker Desktop 环境中执行：

```powershell
./scripts/start-local.ps1
./scripts/collect-local.ps1
```

首次启动自动生成本机配置；已有 `.env` 和持久数据库保留。首次启动构建网页和镜像、迁移并初始化首个管理员。再次启动可用 `-SkipBuild`。如果 PATH 中 Node 较旧，传入 `-NodeExecutable`；pnpm 为独立脚本时传入 `-PnpmCli`。采集时若需本机系统代理，使用 `./scripts/collect-local.ps1 -UseSystemProxy`；也可用 `-Source huawei-campus` 等单独更新。当前没有后台每日调度。

## 已实现的账号与权限

- 管理员通过命令初始化，之后可创建账号、手动授予或撤销 VIP、停用账号。
- 普通用户、有效 VIP 和管理员按动作授权；VIP 到期时立即按普通用户判断。
- 每次请求读取当前角色，旧会话无法保留已撤销的 VIP 或管理员权限。
- 支持查看本人设备会话和撤销会话，跨用户访问返回 404。
- 停用账号会撤销全部设备会话；保留最后一个启用的管理员。
- 账号、角色和会话敏感变更与审计记录在同一事务中完成。

简历与推荐已接入实际接口及网页。VIP/admin 可上传 PDF/DOCX，在本地提取并核对脱敏内容后手动确认资料，或显式授权 DeepSeek 生成待确认草稿；普通账号保留本人文件信息查看和删除权限。未配置模型时资格规则仍可使用。详见 [S3 使用说明](docs/operations/s3-resumes.md) 和 [S3 验收记录](docs/verification/2026-10-15-s3-resume-recommendations.md)。

## 已确定的产品方向

- 先满足个人使用，同时支持管理员、VIP、普通用户三级权限和账号数据隔离。
- 首发电脑网页与手机浏览器，电脑支持列表、表格双视图。
- 覆盖各行业的计算机岗位，包括校招、实习和接受应届生或低经验候选人的社招。
- 后续对接每日更新；第一版目标为稳定跟踪 20 家公司。
- 普通用户使用岗位筛选、收藏和投递管理；VIP 增加上传简历推荐岗位的能力。
- 管理员拥有全部业务权限，手动开通 VIP，并管理岗位和数据来源。
- 通知发送至指定飞书群的自定义机器人，保留站内通知记录。
- 采用 Go、Vue 3/TypeScript、PostgreSQL 和 Docker Compose，面向低成本云部署。

S3 开发与模拟模型验收已完成；真实 DeepSeek 的质量、延迟和费用验收等待本机配置密钥。下一开发阶段为 S4：每日可靠更新、站内事件和飞书群摘要，尚未实现。
