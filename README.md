# 求职助手 · 计算机方向

面向各行业计算机相关岗位，提供官方岗位看板、条件筛选、投递管理，以及 VIP 简历推荐和飞书群通知。

## 当前进度

2026-10-25：S0–S4 已完成开发与对应本地验收，模型及飞书采用隔离模拟。可登录的电脑/手机网页支持列表与表格、组合筛选、官方溯源、收藏、投递状态、备注、事项和历史，并增加“订阅通知”。管理员可维护账号、公司标签、来源开关与岗位发布。不同账号数据隔离，多设备同时编辑通过版本冲突提示保护草稿。

S5 当前接入 **25 家企业、27 个来源**。本批新增 17 家企业的 **663 个岗位，其中实习 155 个**，17 个每日采集任务均已成功；包括智元机器人、拓竹科技、影石创新、寒武纪、文远知行、英伟达、博世等。本机共有 **973 个公开岗位广告，其中实习 250 个**（2026-10-25 发布后快照），不能等同于个人可投数，具体学历、学生身份、领域经验、出勤与时长仍需核对。已有九个来源在本次部署前就发生当日网络失败，其旧岗位保留并显示核验状态；新批次与旧来源的更新时间分别统计。

S3 提供私有简历、本地提取与脱敏、资料确认版本及逐方向岗位匹配；S4 提供北京时间 08:00 更新、09:07 摘要、个人筛选/有效推荐订阅、加密飞书接收配置和可恢复发件箱。用户指定的 219 家企业均已建立逐项对账，其中 18 家已有公开岗位（含原有韶音），184 家岗位或资格待核验，4 家访问受限，13 家网络或证书待复验。真实 DeepSeek 与飞书送达、其余来源接入、云部署和 7 天观察仍待后续验收。

## 打开与更新

当前本机入口：[http://127.0.0.1:18080](http://127.0.0.1:18080)。2026-10-25 Windows 将 7998–8097 列为系统保留范围，8080 无法绑定，因此使用 18080。当前仅绑定本机；手机布局已用独立浏览器上下文验收，真实手机远程访问在部署后提供。登录账号和密码保存在 Git 忽略的 `.env`，分别为 `ADMIN_USERNAME`、`ADMIN_PASSWORD`。

在 PowerShell 7、Node 22.18+（22 系列）、pnpm 11.25.0 和 Docker Desktop 环境中执行：

```powershell
./scripts/start-local.ps1 -HttpPort 18080
./scripts/collect-local.ps1
```

首次启动自动生成本机配置；已有 `.env` 和持久数据库保留。首次启动构建网页和镜像、迁移并初始化首个管理员。再次启动可用 `-SkipBuild`，当前命令为 `./scripts/start-local.ps1 -SkipBuild -HttpPort 18080`；省略 `-HttpPort` 时默认 8080，参数会同时设置回环端口及 API/worker 来源地址。如果 PATH 中 Node 较旧，传入 `-NodeExecutable`；pnpm 为独立脚本时传入 `-PnpmCli`。采集时若需本机系统代理，使用 `./scripts/collect-local.ps1 -UseSystemProxy`；也可用 `-Source huawei-campus` 等单独更新。后台采集若需代理，在忽略的 `.env` 中设置容器可访问的 `COLLECTOR_HTTP_PROXY`、`COLLECTOR_HTTPS_PROXY`。电脑、Docker 和 worker 须持续运行才能执行每日调度；关机后仅补当日。

本机中久来源的 Windows 匿名 HTTPS 正常，Docker 读取仍发生 TLS EOF，因此当前 `.env` 设置 `COLLECTOR_HOST_SOURCES=zjdit-careers`。`start-local.ps1` 会用 Go 构建并在后台启动仅处理指定公共来源的进程；容器继续处理其余来源、计划和摘要，两者共享任务队列、读取锁与重试规则。须保持本机采集进程运行；可单独运行 `./scripts/start-host-collector.ps1` 重启，或加 `-Stop` 正常停止。运行记录在忽略的 `.cache/local/host-collector/`。手动 `collect-local.ps1 -Source zjdit-careers` 也使用本机公开采集路径；没有配置本机来源时保持原容器行为。该可选进程当前针对 Windows，本来源的云端网络与长期稳定性尚待验证。

## 已实现的账号与权限

- 管理员通过命令初始化，之后可创建账号、手动授予或撤销 VIP、停用账号。
- 普通用户、有效 VIP 和管理员按动作授权；VIP 到期时立即按普通用户判断。
- 每次请求读取当前角色，旧会话无法保留已撤销的 VIP 或管理员权限。
- 支持查看本人设备会话和撤销会话，跨用户访问返回 404。
- 停用账号会撤销全部设备会话；保留最后一个启用的管理员。
- 账号、角色和会话敏感变更与审计记录在同一事务中完成。

简历与推荐已接入实际接口及网页。VIP/admin 可上传 PDF/DOCX，在本地提取并核对脱敏内容后手动确认资料，或显式授权 DeepSeek 生成待确认草稿；普通账号保留本人文件信息查看和删除权限。未配置模型时资格规则仍可使用。详见 [S3 使用说明](docs/operations/s3-resumes.md) 和 [S3 验收记录](docs/verification/2026-10-15-s3-resume-recommendations.md)。

## 已确定的产品方向

- 先满足个人使用，同时支持管理员、VIP、普通用户三级权限和账号数据隔离。
- 首发电脑网页与手机浏览器，电脑支持列表、表格双视图。
- 覆盖各行业的计算机岗位，包括校招、实习和接受应届生或低经验候选人的社招。
- 已支持每日持久化更新；第一版目标为稳定跟踪 20 家公司。
- 普通用户使用岗位筛选、收藏和投递管理；VIP 增加上传简历推荐岗位的能力。
- 管理员拥有全部业务权限，手动开通 VIP，并管理岗位和数据来源。
- 通知发送至指定飞书群的自定义机器人，保留站内通知记录。
- 采用 Go、Vue 3/TypeScript、PostgreSQL 和 Docker Compose，面向低成本云部署。
