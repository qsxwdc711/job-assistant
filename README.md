面向各行业计算机相关岗位，提供官方岗位看板、条件筛选、投递管理，以及 VIP 简历推荐和飞书群通知。

2026-10-14：已整理产品设计与实施任务，并完成腾讯、华为、招商银行三类官方来源的公开读取验证。项目包含文档、研究辅助脚本和公开证据，尚未创建应用服务、部署每日采集器、解析真实用户简历、调用模型或发送飞书消息。

## 已确定的产品方向

- 先满足个人使用，同时支持管理员、VIP、普通用户三级权限和账号数据隔离。
- 首发电脑网页与手机浏览器，电脑支持列表、表格双视图。
- 覆盖各行业的计算机岗位，包括校招、实习和接受应届生或低经验候选人的社招。
- 已接入官方来源每日更新；第一版目标为稳定跟踪 20 家公司。
- 普通用户使用岗位筛选、收藏和投递管理；VIP 增加上传简历推荐岗位的能力。
- 管理员拥有全部业务权限，手动开通 VIP，并管理岗位和数据来源。
- 通知发送至指定飞书群的自定义机器人，保留站内通知记录。
- 采用 Go、Vue 3/TypeScript、PostgreSQL 和 Docker Compose，面向低成本云部署。

## 下一阶段

下一阶段建立 Go/数据库工程基线、管理员初始化和三级权限，先完成跨用户访问与 VIP 撤销测试，再接入已验证的岗位来源和网页看板。

岗位模型需要保留华为广告下的岗位意向和方向城市关系；不能把腾讯旧菜单毕业年份当作当前批次门槛；招商的公告与岗位分别核验。当前的 20 家名单仍是接入目标，来源技术可行性、稳定自动运行和个人条件匹配分别统计。
